# 🎓 Student Grade Tracker

A Java-based Student Grade Tracker designed to manage student marks and generate useful academic insights. This project demonstrates the practical implementation of **Object-Oriented Programming (OOP)** and **ArrayList** in Java.

## 🚀 Features

- 👨‍🎓 Add and manage student records
- 📝 Store student marks efficiently
- 📊 Calculate average marks
- 🏆 Find highest marks
- 📉 Find lowest marks
- 🔍 Display student performance
- 💻 Simple and user-friendly console interface

## 🛠️ Technologies Used

- Java
- OOP (Object-Oriented Programming)
- ArrayList
- Console-based Interface

## 📚 Concepts Covered

This project demonstrates:

- Classes & Objects
- Encapsulation
- Methods
- ArrayList
- Loops & Conditional Statements
- User Input Handling
- Basic Data Processing

## ▶️ How to Run

1. Clone this repository
2. Open the project in IntelliJ IDEA or VS Code
3. Compile the Java source files
4. Run `Main.java`
5. Follow the instructions displayed in the console

## 🎯 Purpose

The main goal of this project is to strengthen **Core Java and OOP concepts** by building a practical application that can manage and analyze student performance.
